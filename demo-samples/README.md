# Upload-ready demo documents

These fictional SVG files are safe sample documents for the ReceiptBrain demo. They contain no real personal, financial, or merchant data.

- `01-techmart-laptop-receipt.svg` — shopping receipt, ₹54,990, 24-month warranty
- `02-homecare-appliance-warranty.svg` — warranty certificate, 12-month coverage
- `03-freshbasket-grocery-receipt.svg` — grocery receipt, ₹1,085
- `04-urbanride-phone-receipt.svg` — transport receipt, ₹260

Select them with the app's upload picker. After uploading, open the receipt and enter the date, amount, category and warranty months shown on the document.
